# Huobi

Huobi (Huobi Global) is the former name of HTX, the cryptocurrency exchange founded in 2013, rebranded in 2023. Its Spot REST and WebSocket APIs are profiled in the htx repository, which is canonical. Consolidated 2026-10-13, approved by Kin Lane.

Canonical profile: [api-evangelist/htx](https://github.com/api-evangelist/htx) — https://apis.io/providers/htx/
